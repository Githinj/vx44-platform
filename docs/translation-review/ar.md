## Known concerns

- **“الذكاء الاصطناعي مباشرة”**: The navigation link doesn’t read as the name of a page section.
  Found in: site `nav.liveAi`
- **“محوّل”**: “Adapter” reads as a power converter here. Use the word customers would use for a small network box.
  Found in: site `home.features.items.0.body`, site `home.faq.items.1.answer`, site `demo.nextSteps.2`, app `status.org.adapter_shipped`
- **“الرئيسية”**: Used as the label of the navigation landmark, but it usually means “home page”.
  Found in: site `common.homeLabel`, site `common.mainNav`, site `notFound.home`, site `errorPage.home`, app `common.homeLabel`, app `client.primaryContact`
