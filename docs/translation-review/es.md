# Translation review: Spanish (US) (`es`)

Generated by `npm run translations:export` from the dictionaries in `src/i18n/`. **Don't edit the tables here:** write corrections in the *Reviewer note* column of a copy, or straight into `src/i18n/`, then re-run the script. See [README.md](README.md) for how to review.

All Spanish (US) text was drafted by AI and needs a native speaker's review before launch (SEC-259). The English version governs the legal pages.

## Known concerns

- **“falsas alarmas se quedan aquí”**: Reads as if the false alarms are kept here. The English line it translates is being softened (SEC-282, waits on Amar), so change both together.
  Found in: site `home.how.steps.1.body`
- **“subencargado”**: Unfamiliar to US Spanish readers. Consider “subprocesador” or a plain description (“un proveedor que guarda el video por nosotros”).
  Found in: site `home.faq.items.2.answer`
- **“Ahora alguien está mirando”**: Suggested instead: “Ahora alguien las vigila”.
  Found in: site `meta.ogDescription`, site `home.headline.1`
- **“demostración”**: “demo” and “demostración” are both used across the site. Pick one and use it everywhere.
  Found in: site `meta.demo.title`, site `meta.demo.description`
- **“Alertas de movimiento con IA”**: Plan list item. The page promises not to flag every shadow, so “movement” alerts sound wrong. This is pricing copy: the wording is a decision for Amar (SEC-280 finding 10).
  Found in: site `home.pricing.includes.0`
- **“en la entrada”**: The alert line says “en la entrada” while the camera label beside it says FORECOURT (camera labels stay in English by design). Decide whether the event line should match the camera name.
  Found in: site `home.alert.event`
